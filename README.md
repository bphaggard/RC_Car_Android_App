# Android App to control RC car for repo RC_Car_Pico

This Android app allows you to control an RC car through a Bluetooth Low Energy (BLE) HM-10 module.
It is built using Kotlin and Jetpack Compose, following MVVM + Clean Architecture principles.

✨ Features
- Scan & connect to HM-10 BLE module
- Directional control (forward, backward, left, right) with press & hold interaction
- Toggle lights (single button on/off)
- UI feedback when connected / disconnected
- Safe permission handling (Bluetooth + Location on Android 12+)

🛠 Tech Stack
- Kotlin + Jetpack Compose for UI
- MVVM + Clean Architecture
- Android BLE APIs for HM-10 UART communication
- Material3 Design Components
